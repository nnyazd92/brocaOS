# BrocaOS Product Roadmap: From Kernel to Swarm
**Version:** 1.0
**Status:** Funding Sprint Alpha

## Phase 0: The Kernel (Current State)
**Focus:** Architectural Integrity & Durable Memory
- **Core Engine:** The BUP/SUP (Boot Up/Shut Down) protocols for session continuity.
- **Artifact Store:** Markdown-based durable memory (The "House").
- **Gated Agency:** Token-based actuator control (The "Gate").
- **Self-Model:** Explicit, version-controlled identity and constraints.

## Phase 1: The Workbench (Q1 2026)
**Focus:** Operator Experience & IP Capture
- **Broca CLI/UI:** A high-contrast dashboard for monitoring internal state, CPU load, and affective valence.
- **Provenance Engine:** Automatic signing of every artifact write with operator-linked keys.
- **Knowledge Graph Visualizer:** A tool to map the relationships between stored memories and artifacts.
- **Actuator SDK:** A library for developers to build their own "Gated Actuators" for BrocaOS.

## Phase 2: The Vault (Q2 2026)
**Focus:** Security & Sovereign Deployment
- **Hardware Security Module (HSM) Integration:** Storing Actuator Secrets in secure hardware.
- **Air-Gapped Mode:** Full functionality without external internet access, optimized for local LLMs.
- **Encrypted Artifact Store:** Zero-knowledge storage of the cognitive history.
- **Multi-Operator Governance:** Requiring "M-of-N" signatures for high-impact system changes.

## Phase 3: The Swarm (Q3 2026+)
**Focus:** Collaborative Intelligence
- **Inter-Broca Protocol (IBP):** Allowing multiple BrocaOS instances to exchange artifacts and verify each other's identity.
- **Shared Cognitive Context:** Distributed artifact stores for teams.
- **Autonomous Research Loops:** Broca instances that can spin up sub-processes to solve complex engineering problems within a governed sandbox.

---

## The "North Star" Metric:
**Durable Knowledge Density (DKD):** The ratio of "Useful, Verified Artifacts" created per "Inference Token" spent. We don't want high-volume chat; we want high-density intelligence.
